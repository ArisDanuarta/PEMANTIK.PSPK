# Pemantik Mobile - Flutter App (Siswa)

## Overview
Aplikasi mobile Flutter untuk siswa mengerjakan asesmen literasi & numerasi.

## Fitur Utama
- Login dengan username + PIN (tanpa email, ramah anak)
- Dashboard pribadi siswa
- Mengerjakan soal interaktif (pilihan ganda, drag & drop, audio, video, voice recording)
- **Offline-First**: jawaban disimpan lokal via SQLite (Drift ORM)
- Auto-sync saat koneksi tersedia

## Tech Stack
- Flutter (iOS & Android)
- Drift ORM (SQLite offline)
- connectivity_plus (deteksi koneksi)
- Supabase Flutter SDK
